Pop Out for Todoist

Open a task on Todoist web, then click the red Pop out button next to “Add sub-task” or press Shift+P. Check it off in the floating window to complete it.

1. API token

In Todoist, go to Settings → Integrations → Developer and copy your API token.

The token is stored only in this browser profile and is sent only to api.todoist.com.

2. Site access

The extension needs access to app.todoist.com (to show the button) and api.todoist.com (to read and complete tasks).
